Guide Python :

I Envir virtuel :

Pour dev proprement en python il est necessaire d'installer un envir virtuel

Python3 -m venv .venv : permet de creer un dossier qui va contenir
 l'environnement virtuel


une fois l'environnement virtuel créé il faut dire au shell
d'utiliser ce context. 

: source .venv/bin/activate


==> on peut alors installer toutes les dependances liées au projet

==> Pour quitter l'envir vituel : deactivate
