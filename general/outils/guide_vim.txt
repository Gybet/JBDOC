VIM

créer un fichier : 

	commande : vim <nom fichier>

Vim permet de basculer entre différents modes de commande.

Normal : pour naviguer et editer
Insert : pour insérer et modifier du text
Command line : pour des opérations


Pour passer en mode Normal : touche echape
Pour passer en mode insert (depuis le normal) --> taper "i"
Pour passer en mode command (depuis le mode normal) --> appuyer sur la touche ":"


En mode commande les actions suivantes sont possible : 

:q! --> quitte sans sauvegarder:
:x! --> quitte et sauvegarde
:set number --> affiche les numéros de ligne
: <numero ligne> --> saute au numéeo de ligne indiqué
:$ --> saute à la dernière ligne 
:w sauvegarde le fichier

En mode normal : les actions suivantes sont possibles :

u --> undo : reviens en arrière
v + fleche --> permet la selection de texte
y --> copy
p --> paste
o --> créer une nouvelle ligne sous la ligne du curseur
dd --> supprime la ligne du curseur
x --> supprime un caractere
